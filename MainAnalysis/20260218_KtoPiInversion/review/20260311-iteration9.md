## Concrete solution to the refolding problem

I would recommend the following resolution path.

### 1. Promote the tail merge from a hidden heuristic to an explicit scanned parameter

Current code:

- `DetermineOverflowKeepBins(hRecoCountsFine, 100.0)`

Recommended change:

- Expose the number of kept `dN_{ch}/d\eta` bins as an argument to
  `runDNdEtaUnfolding_BayesSVD.C`.
- Scan at least:
  - `keepBins = 8`
  - `keepBins = 9`
  - `keepBins = 10`

Why:

- Right now the tail merge is chosen indirectly from reco counts only.
- The real problem is species-level migration quality and refolding quality, not
  just event count per reco bin.

### 2. Add species-level closure outputs, not only ratio-level closure

Current outputs already include:

- species-level refolding histograms
- ratio-level closure and ratio-level refolding histograms

What should be added:

- `K_unfolded / K_truth` vs `dN_{ch}/d\eta`
- `\pi_unfolded / \pi_truth` vs `dN_{ch}/d\eta`

Why:

- The current note already shows that ratio-level cancellation can hide
  species-level bias.
- The species-level tail problem should therefore be diagnosed with species-level
  closure, not only with `K/\pi`.

### 3. Use an explicit acceptance rule for the scanned tail binning

Suggested acceptance criteria for the chosen `keepBins`:

1. ratio-level `K/\pi` refolding remains acceptable
2. species-level refolding no longer collapses catastrophically in the last bins
3. final merged-bin purity and stability both improve to a clearly less-marginal
   level than the current `0.20-0.25` range

Practical reviewer target:

- if the last visible species-level refolding bin is still around `0.1-0.2`,
  the tail merge is still too weak

### 4. If no reasonable tail merge fixes the last bin, downgrade the last `dNch/deta` bin

If `keepBins = 8, 9, 10` all fail the species-level criteria, the clean fallback is:

- quote the ratio-level result as valid only up to the penultimate bin, or
- keep the last bin as a status/diagnostic overflow point with explicit caution

That is better than keeping a visually precise but methodologically weak last bin.

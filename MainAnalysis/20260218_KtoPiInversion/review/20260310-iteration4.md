### 1. High: add a refolding closure check for both `N_tag` and `dNch/deta`

Current status:

- What is still missing is a direct reco-space refolding test.

Requested implementation:

- Starting from the unfolded nominal Bayes result, fold the unfolded species
  spectra back through the same response matrix used for the unfolding.
- Compare the refolded reco prediction to the measured reco spectrum.
- Do this for both:
  - `N_tag` unfolding
  - `dNch/deta` unfolding

Requested note update:

- Add a short validation paragraph in the unfolding section near
  `overleaf_repo_git/main.tex:325`.
- Add one figure for `N_tag` and one figure for `dNch/deta`, or one combined
  two-panel figure if space is tight.
- The caption should state clearly:
  - what is unfolded
  - what is refolded
  - that the comparison is performed in reco space
  - whether agreement is within statistical precision

Why this is important:

- Refolding is one of the cleanest internal consistency checks for any unfolding.
- It tests whether the unfolded solution actually reproduces the measured input
  after detector smearing.

### 2. High: add a mismatched-shape closure test instead of relying only on nominal MC closure

Current status:

- The current closure tests are useful, but they still validate the method on a
  truth shape closely tied to the response construction.

Requested implementation:

- Build at least one nontrivial truth-shape stress test by reweighting the MC
  truth distribution before detector smearing.
- Suggested examples:
  - tilt the truth `K/pi` shape versus `N_tag`
  - harden or soften the high-activity tail
  - distort the `dNch/deta` dependence with a smooth monotonic weight
- Then run the same unfolding chain and show whether the method recovers the
  injected truth.

Requested note update:

- Add this as a dedicated robustness paragraph near the existing unfolding
  validation material around
  `overleaf_repo_git/main.tex:357`.
- Include one summary figure with:
  - injected truth
  - unfolded result
  - ratio unfolded / injected

Why this is important:

- Nominal closure alone is too easy.
- A mismatched-shape test gives a more realistic estimate of prior dependence and
  model sensitivity.
